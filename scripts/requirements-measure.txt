# On a managed GPU image (Kaggle, Colab, a cloud notebook) DO NOT install this file
# with `-U`. Those images ship a torch built against their own CUDA, and pip will
# happily replace it with a generic PyPI build that does not match -- which takes
# torchvision, torchaudio and the CUDA toolkit down with it, and then transformers
# fails with a confusing `Could not import module 'LlamaConfig'`. There, install
# nothing: the stack is already present. See the note on torchao below.

#   but only versions above 0.16.0 are supported
