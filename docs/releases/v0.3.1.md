# FitCheck v0.3.1 beta

FitCheck 0.3.1 beta adds holdout-based safety verdicts and refreshes the published evidence summary. FitCheck estimates LLM memory from model configuration metadata. The measurements below are narrow and do not promise that an unmeasured training or serving job will fit.

## Release highlights

- Adds conservative `safe`, `uncertain`, and `does_not_fit` training verdicts. The holdout-based reserve applies only to the matching measured Tesla T4 configuration; other paths use the documented point-estimate margin policy.
- Ships four CUDA-overhead profiles for Tesla T4 × {eager, flash-like SDPA} × {unquantized, NF4}. Other GPUs, INT8, checkpointing-off training, and inference use the default 500 MiB plus 5% profile.
- Publishes the manifest-backed measurement roles: 79 archived rows, 49 fitted rows, 57 calibration/repeat rows scored, 12 final accuracy holdout rows kept out of the fit, and 10 legacy rows excluded.
- Improves model/config input validation and reports Hugging Face Hub failures with a clear error.

## Accuracy evidence

Across the 57 scored calibration/repeat rows, process-tier absolute error is 2.4% mean and 13.9% worst; the five physical tensor formulas are 0.7% mean and 4.6% worst. These rows are all from one Tesla T4 (sm_75) with FP16 compute.

The separate 12-row accuracy holdout reports tensor error ±1.4%, process MAE 5.4%, and worst process under-prediction −15.3%. Its exact scope is one Tesla T4 (sm_75), NF4, FP16 compute, LoRA r=16 targeting q/k/v/o (without double quantization), batch size 1, AdamW with FP32 states, gradient checkpointing, sequence length 1024, six eager rows, and six rows using SDPA's memory-efficient backend. The six models are Qwen/Qwen2.5-7B-Instruct, Qwen/Qwen2.5-Coder-1.5B-Instruct, deepseek-ai/deepseek-coder-1.3b-instruct, meta-llama/Llama-3.2-1B-Instruct, meta-llama/Llama-3.2-3B-Instruct, and mistralai/Mistral-7B-Instruct-v0.3. This is not validation on a second GPU, BF16, or real FlashAttention-2.

A separate 12-case boundary set has six predicted-safe and six predicted-unsafe ceilings against the T4's 14,000 MiB safety budget; all 12 point-estimate outcomes match the measured budget outcomes. This boundary set and the accuracy holdout were never used for fitting.
